# 04 User experience

Implements workplan WP1.8 and the agreed StoryStage vocabulary.

## 1. Branding (WP3)

| Where | Alice today | StoryStage |
|---|---|---|
| Window title | "Alice 3" | "StoryStage" (plus the world name and an unsaved marker, as now) |
| About dialog | Alice credits | StoryStage name and version, "Based on Alice 3.9.1.0", then the Alice, Looking Glass and EA credits and licences from NOTICE |
| User data folder | `Alice3` (`getApplicationSubPath`) | `StoryStage`, so an installed Alice is untouched |
| Splash, icons | Alice | StoryStage artwork (WP3.4) |
| Run button | "Run…" | "Rehearse…" |
| Starting templates tab | "Blank Slates" | "Backdrops" |
| Gallery heading | (gallery tabs) | "Cast and props" heading above the gallery tabs |

Only the English (`en`, `en_CA`) strings change in TR1; other locales keep Alice's wording until translated. Strings are changed in the existing `.properties` files, not in code.

## 2. Prompter panel

Docked on the right of the code editor and the scene editor (spec 00, section 2), default width 320 px, collapsible to a 28 px strip with a "Prompter" tab. Hidden completely when the Prompter is off or locked.

```
┌ Prompter ───────────────── [Show me how ▾] [⋯] ┐
│ Prompter: Hi! Tell me what to put on stage.    │
│ You: put a cat on the moon and make it wave    │
│ Prompter: Adding a cat in front of the camera. │  ← caption of the step being spoken
│   ✓ Add cat   ✓ Turn cat to face camera        │  ← steps, each clickable (selects the block)
│   ⟳ Add "say Hello"                            │
├────────────────────────────────────────────────┤
│ [ Tell the Prompter what to stage…           ] │
│ [🎤 Hold to talk]  [Send]  [Stop]               │
│ Undo this request · This month: 14 requests, ~£0.80 │
└────────────────────────────────────────────────┘
```

**Menu (⋯):** New conversation · Let the Prompter see the scene (tick) · Spoken steps (tick) · Set up… · About the Prompter.

**Modes:** "Show me how" (default), "Build it", and "Explain only" (forced when locked to explain-only).

## 3. States

| State | Shown | Controls |
|---|---|---|
| Not set up | "Set up the Prompter to use it with your own Claude account." | **Set up…** |
| Ready | Greeting, or the transcript so far | Input, Hold to talk, Send |
| Listening | Pulsing mic, "Listening… let go when you're done" | Release to stop |
| Transcribing | "Turning your words into text…" | Stop |
| Thinking | "The Prompter is thinking…" with elapsed seconds | Stop |
| Building | Step list growing; caption of the current step | Stop |
| Speaking | Caption highlighted | Stop (speech only) |
| Done | Summary; steps list | Undo this request |
| Error | Message from spec 01 section 5, with its action | As listed |
| Offline | "You're offline…" | Try again |

## 4. Accessibility

- Every control is reachable by keyboard: Ctrl+Shift+P focuses the input; Ctrl+Space is hold to talk; Esc stops.
- Captions are always shown, whether or not speech is on.
- Step entries have text labels (not only icons), and colours meet 4.5:1 contrast against the FlatLaf theme.
- Panel text uses the IDE's font scaling.

## 5. Words used in the panel

Use the learner's view: "the cat", "your scene", "the move block", never AST, field, invocation, edit or token. Steps are named after what changed ("Add cat", "Make cat say Hello"). Errors say what happened and what to do, with no apologies.
